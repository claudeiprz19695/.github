<p>选购住宅 IP 最容易出问题的地方，不是买贵了，是买回来才发现不符合预期：标着美国结果是机房段，标着独享结果同段还有别人，说好不限并发结果十个连接就断流。这篇把选购时要看的五个项目做成清单，每一项对应一个常见误判，给出该问的问题、判断标准和验证方法，谈的时候照着念，基本不会被话术带偏。</p>

<h2>一、清单怎么用：五项各对应一个常见误判</h2>
<p>五项是地区、纯净度、并发、计费、售后。顺序不能乱：地区决定能不能用，纯净度决定稳不稳，并发决定多人能不能同时用，计费决定超支风险，售后决定出事时有没有人管。前两项不合格直接放弃，后三项谈条件。</p>
<p>清单的用法是逐项打勾，而不是整体感觉。谈完一轮把五项填满，再对比两家，比听销售讲十分钟参数有用。下面每一项都给了具体的验证动作，能在十分钟内自己完成。</p>

<h2>二、地区项：别被"美国"两个字带过</h2>
<p>常见误判是把国家当成地区。美国东西海岸的延迟差一倍，IP 库里的城市标注也可能对不上。要问的是三件事：IP 的注册国家与城市、ASN 属于哪家运营商、rDNS 是什么样子。三项都指向同一地区的消费级 ISP，才算真的落在这个地区。</p>
<h3>该问的问题</h3>
<p>直接问："这个段的 ASN 是多少，rDNS 模板是什么，能不能给一个测试 IP。"拿到测试 IP 后自己跑：curl -s https://ipinfo.io/1.2.3.4 看 country 和 org，whois -h whois.cymru.com " -v 1.2.3.4" 看 AS 名称，dig -x 1.2.3.4 +short 看反解。org 里出现 cloud、hosting、datacenter 字样，就不是住宅。</p>
<h3>合格线怎么定</h3>
<p>国家与目标一致、ASN 是消费级运营商、rDNS 是运营商风格主机名，三项齐全算合格。只有国家一致、ASN 是机房的，属于"地理对但类型错"，价格应该明显低于住宅，别按住宅价买。</p>

<h2>三、纯净度项：住宅标签不等于可用</h2>
<p>纯净度不是标签，是历史。一个地址以前被用来做过什么，会以信誉分的形式留下来。判断方式是多源交叉：ping0 看风险等级，scamalytics 看欺诈分，ipqualityscore 看代理与滥用标记，三家结论一致才算有把握。单看一家容易被误导，因为各家的库更新节奏不同。</p>
<h3>常见误判：新段一定干净</h3>
<p>新切出来的段没有历史记录，看起来"干净"，但也意味着没有正常使用痕迹。有些场景下，完全没有历史的地址反而显得突兀。合理的做法是选有正常家庭使用背景的地址，而不是追求"零记录"。</p>

<h3>验证动作</h3>
<p>拿三个测试 IP，分别跑上述三家查询，记录分数；再用 curl 访问一个会返回 IP 类型的接口，看是否被识别为 proxy 或 vpn。三项动作十分钟内能做完，比看宣传页可靠。</p>

<h2>四、并发与计费项：两个最容易被话术带偏的参数</h2>
<p>并发要看的是"同时连接数"而不是"同时在线人数"，这两个概念经常被混用。一个浏览器标签页在长对话时可能维持 4 到 6 条连接，五个标签就是二三十条。如果对方说"支持 10 人同时用"，要追问是 10 个连接还是 10 个终端。</p>
<h3>计费的三种口径</h3>
<p>按 IP 数包月、按流量 GB、按小时租用。包月适合长期固定的账号，流量计费适合不稳定用量，按小时适合短时任务。坑在于混合计费：有些方案基础费按 IP 收，超出流量再按 GB 加收，两头都占。签之前把"超出后单价"问清楚。</p>

<h2>五、售后项：出问题时能拿到什么</h2>
<p>售后不是"有没有客服"，是"出问题能不能换、多久换、换的时候算不算钱"。三个具体问题：IP 被封能不能免费换、换的话多久生效、当月已用流量怎么算。能明确回答这三条的，基本可以合作；含糊其辞的，出了问题大概率扯皮。</p>
<h3>要留下的凭证</h3>
<p>报价单、合同里的 SLA 条款、工单编号。SLA 里重点看两条：可用性承诺的百分比，以及未达标时的补偿方式（按天折算还是换线路）。没有书面 SLA 的服务商，价格再低也要谨慎。</p>
<h3>试用期的价值</h3>
<p>能提供三天到一周试用的，优先考虑。试用期内把上面四项全测一遍，比任何承诺都实在。试用期不要只测连通性，要按真实使用强度跑一遍，包括并发、上传、长时间保持连接。</p>

<h2>常见问答</h2>
<h3>价格特别低的住宅 IP 通常问题出在哪？</h3>
<p>答：多数是共享池冒充足量独享，或者机房段贴上住宅标签。验证方法是查 ASN 和 rDNS，再看同段邻居的风险评分，两项都过关的低价才值得考虑。</p>
<h3>卖家说"原生 IP"，这个说法可信吗？</h3>
<p>答：原生通常指 IP 的注册地与使用地一致、归属运营商而非转售商。判断依据还是 ASN 与 rDNS，说辞本身不构成证据。要求给测试 IP 自己查。</p>
<h3>包月和按流量，长期用哪个便宜？</h3>
<p>答：日流量稳定在几百兆以上的选包月，波动大或只用几天的选流量。粗略分界是每月 5GB，超过这个量包月通常更划算，具体还要看超出单价。</p>
<h3>售后响应速度怎么在买之前判断？</h3>
<p>答：提一个技术问题看回复质量，比问"你们响应多快"有用。能直接给出排查命令和参数解释的，通常技术底子在；只会发话术模板的，出问题时也帮不上忙。</p>
